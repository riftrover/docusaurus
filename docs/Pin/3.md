# メンションを許可しよう

下記のコマンドで「通知する」を選択することで、メッセージにメンションが含まれている場合、メンション対象者に通知されるようになります。

```
/mention
```

:::warning

例えば、メッセージに `@everyone` が含まれている場合、Pin留めするたびに `@everyone` が通知されます。

:::

:::info

デフォルト設定では、`@everyone`,`@here`,`@user`,`@role`などのメンションは通知されないよう設定されています。

:::
